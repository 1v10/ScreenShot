# 40. 移除关于页与关联功能，默认使用首个颜色

- Status: Accepted
- Context: 用户要求移除设置中的关于说明页及其全部关联功能，并将截图默认色由第二个改为第一个色块。
- Decision: 设置只保留通用、工具栏、快捷键、保存、外观五页；删除关于页的项目地址、在线第三方许可入口、支持项目赞赏码，以及手动/自动更新的界面、后台检查、下载替换、配置和开发辅助工具。保留发布包 LICENSE 与 THIRD-PARTY.md 以履行许可声明。截图和贴图编辑每次初始化优先选择颜色 1；若被隐藏则使用首个可见颜色，全部隐藏时仍以颜色 1 绘制。旧配置中的更新字段由 serde 忽略，不影响其他偏好。
- Consequences: 应用不再检查或下载安装更新，升级通过手动替换本地程序完成。删除仅供更新使用的依赖和 WinHTTP 特性。自定义色块内容与显隐偏好继续有效，默认颜色不硬编码为白色，而是读取首个可见色块的实际颜色。
