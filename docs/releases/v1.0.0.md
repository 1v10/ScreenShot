# ScreenTrans v1.0.0

- 软件名、窗口标题、托盘、程序文件和发布包统一为 ScreenTrans。
- 截图默认选中第一个可见颜色，颜色 1 的预设为白色。
- 界面使用 Segoe UI，中文优先回退微软雅黑；标注字体仍可单独选择。
- 增加 Windows x64 自动构建、tag 版本校验和 GitHub Release 产物发布。

下载 ZIP 解压后运行 `ScreenTrans.exe`，或直接运行独立 EXE。发布版需要管理员权限，启动后在托盘常驻，F1 截图、F3 贴图。

首次从 AirSnip 升级，请先退出旧程序并关闭旧版自启。新配置位置为 `%APPDATA%\screentrans\config.toml`；新配置不存在时读取旧 `%APPDATA%\airsnip\config.toml`，保存设置后写入新目录。

附件中的 `.sha256` 为 ZIP 和独立 EXE 的 SHA-256 校验值。程序保留 GPL-3.0-only 许可，ZIP 包含许可证和第三方声明。
